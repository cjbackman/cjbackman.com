# Custom Hugo Theme: cjbackman

## What We're Building

A custom Hugo theme named `cjbackman` that replaces the third-party `mini` submodule. The aesthetic is minimalist — predominantly white, monospace body text, single column, minimal navigation chrome. The goal is to own every line of the theme while preserving the site's functional features (Mermaid diagrams, MathJax math, social links, Nifties section).

The scaffolded theme files (generated by `hugo new theme cjbackman`) already exist at `content/themes/cjbackman/` but are in the wrong location. Hugo expects themes at `themes/cjbackman/`.

## Why This Approach

We're building on the scaffold (Approach A) rather than forking `mini` or doing a CSS-only overlay. The scaffold gives us a clean, minimal starting point using Hugo 0.146+ conventions (`_partials/` prefix, Hugo Pipes for CSS/JS with fingerprinting). Forking `mini` would leave dead code to delete; CSS-only would remain dependent on a submodule we don't control.

## Key Decisions

- **Typography**: Monospace body text (`ui-monospace, Menlo, Consolas, monospace`). Headings may use same monospace stack for full consistency.
- **Layout**: Single column, centered, ~680px max content width. White background (`#fff`). Very little margin decoration.
- **Navigation**: Minimal header — site name/title as a link + a small set of nav links. No avatar or biography block (a departure from the current mini theme).
- **Homepage**: Paginated post listing similar to what mini provides — each entry shows title (link), date, and summary text. 3 posts per page.
- **Footer**: Social links (email, LinkedIn) + simple copyright. No "powered by" line.
- **Special features to preserve**:
  - Mermaid diagrams (two-file pattern: render hook sets flag, `single.html` injects ESM script)
  - MathJax v4 via CDN (matching `config.yml` passthrough delimiter config)
  - Tags taxonomy
  - Nifties page (uses `static/css/custom.css` card grid)
  - Custom navigation paths: `/on` (not `/posts`), `/nifties`, `/is-a-technologist`
- **CSS delivery**: Hugo Pipes (`assets/css/main.css`) with minify + fingerprint in production — already wired in the scaffold's `_partials/head/css.html`.
- **No JavaScript** beyond Mermaid and MathJax (loaded conditionally). No dark mode initially.

## Open Questions

- **Avatar/bio block**: Current mini theme shows avatar + bio tagline on the homepage. The new theme drops this per the "minimal navigation chrome" preference — confirm this is intentional.
- **Pagination style**: Should paginator prev/next controls be plain text links (`← older / newer →`) or match mini's current style?
- **Tag display on posts**: Mini shows tags at the bottom of each post. Keep? The scaffold's `terms.html` partial already handles this.
- **Social icon style**: Current mini theme uses inline SVG icons. New theme could use text links (`email`, `linkedin`) instead, which fits the minimal/monospace aesthetic better.
